# Task Rewards Front End

Static GitHub Pages front end connected to the existing Supabase project.

Supabase project ref: `egeftdnvgcqjjavrpohd`

Included:
- Email sign-up/sign-in
- User profile and points display
- Active task listing
- Task submission/proof
- Manual redemption request
- Notifications

Important: `config.js` contains only the public Supabase publishable key. Never put a service-role/secret key in the browser or GitHub.
